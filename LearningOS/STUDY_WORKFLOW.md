# LearningOS Study Workflow

LearningOS는 **ChatGPT 웹/모바일에서 대화하며 공부하고, Day가 끝난 뒤 그 대화를 교재로 정제하는 방식**을 기본으로 합니다.

## 핵심 철학

처음부터 완벽한 PDF를 고정해서 읽지 않습니다.

```text
초기 교재
→ 실제 학습
→ 질문
→ 쉬운 재설명
→ 오해 수정
→ 최종 교재
→ PDF
→ GitHub
→ Book 누적
```

즉, 교재가 학습자와 함께 성장합니다.

## 하루 시작

예:

```text
APEX Day 1 시작
ATLAS Day 1 시작
```

Day 시작 시 그날 약 3~4시간 학습 분량의 **초기 교재**를 채팅에 제공합니다.

초기 교재는 다음 흐름을 가집니다.

```text
1. 이전 Day에서 이어지는 이야기
2. 오늘의 미스터리/문제
3. 가장 기초적인 배경
4. 핵심 개념
5. 그림·텍스트 구조도
6. 실제 논문 또는 실제 프로젝트 연결
7. 현실에서의 사용
8. 확인 질문
9. 다음 Chapter로 연결
```

## Chapter 방식

한 Day는 여러 Chapter로 나눌 수 있습니다.

```text
Day 4
├─ Chapter 1 — 문제 상황
├─ Chapter 2 — 기초 배경
├─ Chapter 3 — 핵심 개념
├─ Chapter 4 — 실제 사례
└─ Chapter 5 — 복습과 다음 이야기
```

중간에 멈춘 뒤에는:

```text
APEX 계속
ATLAS 계속
```

이라고 입력해 마지막 Chapter부터 이어갑니다.

## 질문하는 순간이 교재 집필의 일부다

막히면 바로 질문합니다.

```text
APEX 질문: Tensor와 Matrix가 왜 다른지 모르겠어.
ATLAS 질문: PR-AUC가 양성률에 영향을 받는다는 게 이해 안 돼.
```

답변은 가능하면 다음 순서로 제공합니다.

```text
쉬운 한국어
→ 일상 비유
→ 그림/텍스트 도식
→ 실제 사례
→ 전문 용어
→ 논문/실무에서의 표현
```

좋은 질문과 보충 설명은 해당 Day의 최종 교재에 반영합니다.

## Day 완료

공부를 끝내면:

```text
APEX Day 1 완료
ATLAS Day 1 완료
```

이라고 입력합니다.

완료 단계에서는 다음을 수행하는 것이 원칙입니다.

```text
1. 오늘 배운 흐름 재구성
2. 질문했던 부분을 더 자연스럽게 본문에 삽입
3. 자주 헷갈릴 오해 정리
4. 핵심 그림/도식 보강
5. 오늘의 5문장 요약 추가
6. 설명형 확인 문제 추가
7. 다음 Day 떡밥 추가
8. 최종 PDF 생성
9. GitHub Day 원고 업데이트
10. Book 누적본에 편입
```

따라서 `Day N 완료` 뒤의 PDF가 해당 Day의 **정식 확정판**입니다.

## PDF의 역할

PDF는 학습 전에 고정된 정답지가 아니라 **학습 후 완성되는 개인 교재**입니다.

```text
초기 버전: 채팅에서 읽고 질문하기 위한 교재
최종 버전: 질문과 보충설명을 반영한 PDF
```

필요하면 중간에도 PDF를 만들 수 있지만, 정식 보관본은 완료 후 버전을 우선합니다.

## Book의 역할

각 프로젝트는 Day PDF 30개가 최종 목적이 아닙니다.

완료된 Day를 계속 누적해 하나의 책을 만듭니다.

```text
APEX Book
= AI Paper Journey

ATLAS Book
= Data Analytics Journey
```

Book은 단순 PDF 이어붙이기가 아니라 Day 사이의 중복을 줄이고 연결 문장을 다듬어 **하나의 연속된 책**으로 만드는 것을 목표로 합니다.

## 완료 기준

하루 내용을 모두 외우지 않아도 됩니다. 다음 세 가지가 되면 완료할 수 있습니다.

1. 오늘의 핵심 문제와 해결 아이디어를 자신의 말로 설명한다.
2. 핵심 구조의 입력 → 처리 → 출력을 따라간다.
3. 실제 논문/프로젝트에서 오늘 배운 개념을 발견하면 대략적인 역할을 안다.

## 시간이 부족한 날

다음처럼 축약할 수 있습니다.

```text
APEX 오늘 60분 핵심 모드
ATLAS 오늘 90분 핵심 모드
```

핵심 문제, 개념, 구조 그림, 실제 연결, 5문장 요약만 진행하고 이후 필요할 때 심화합니다.

## 학습의 핵심 질문

새로운 기술과 분석 방법을 볼 때 항상 다음 질문을 반복합니다.

```text
무슨 문제가 있었나?
왜 기존 방법으로 부족했나?
새로운 아이디어는 무엇인가?
실제로 어떻게 작동하나?
현실에서는 어디에 쓰이나?
어떤 한계가 남아 있나?
```

LearningOS의 목적은 지식을 따로 암기하는 것이 아니라, 이 질문들을 통해 서로 연결된 지식 지도를 만드는 것입니다.
