# LearningOS Study Workflow

LearningOS는 파일을 먼저 읽는 방식보다 **ChatGPT 웹/모바일에서 대화하며 공부하는 방식**을 기본으로 합니다.

## 하루 학습 구조

한 Day는 약 4시간 분량이지만 한 번에 몰아서 읽지 않습니다.

```text
Session 1 — 이야기와 배경
Session 2 — 핵심 개념
Session 3 — 실제 논문/자료 탐험
Session 4 — 현재 활용 + 복습
```

각 Session은 앞 내용에서 자연스럽게 이어져야 하며, 새로운 용어는 반드시 아래 순서로 소개합니다.

```text
쉬운 한국어
→ 비유
→ 그림/텍스트 도식
→ 실제 용어
→ 논문 표현
→ 필요할 때만 수식
```

## 질문 방식

모르는 부분을 바로 멈추고 질문합니다.

```text
APEX 질문: Tensor와 Matrix 차이가 아직 헷갈려.
```

또는 원문을 붙여 넣습니다.

```text
APEX 질문:
"The model projects queries, keys and values..."
이 문장이 무슨 뜻인지 모르겠어.
```

답변은 가능하면 다음 순서로 받습니다.

```text
1. 쉬운 설명
2. 일상 비유
3. 구조 그림
4. 실제 AI에서의 사용
5. 논문에서는 어떻게 표현되는지
```

## 완료 기준

하루 내용을 100% 외우는 것이 목표가 아닙니다. 아래 세 가지가 되면 그 Day를 완료할 수 있습니다.

1. 오늘 개념의 핵심을 자신의 말로 설명할 수 있다.
2. 핵심 구조의 입력 → 처리 → 출력을 따라갈 수 있다.
3. 실제 논문에서 오늘 배운 용어를 발견했을 때 대략적인 역할을 안다.

## 복습 방식

Day 완료 시 다음을 정리합니다.

- 오늘의 핵심 5문장
- 가장 중요한 개념 3개
- 헷갈리는 개념 1~3개
- 논문에서 실제로 본 표현
- 다음 Day에 이어질 질문

## PDF 사용

PDF는 기본 학습 화면이 아닙니다. 채팅에서 공부한 뒤 다음처럼 요청합니다.

```text
APEX PDF
```

그날의 질문, 보충 설명, 이해하기 어려웠던 부분까지 반영한 **개인 복습 교재**를 만드는 용도로 사용합니다.

## 하루를 놓쳤을 때

처음부터 다시 시작하지 않습니다.

```text
APEX 계속
```

이라고 입력해 마지막 진도부터 이어갑니다.

## 시간이 부족한 날

4시간을 확보하지 못하면 핵심 모드로 진행합니다.

```text
APEX 오늘 60분 핵심 모드로 해줘
```

핵심 개념, 그림, 실제 논문 연결, 5문장 복습만 진행하고 정상 학습으로 인정합니다.

## 학습의 핵심 원칙

LearningOS는 많이 외우기보다 **개념 사이의 연결을 만드는 것**을 우선합니다.

새로운 기술을 만날 때마다 다음 네 질문을 반복합니다.

1. 어떤 문제가 있었나?
2. 기존 방식은 왜 부족했나?
3. 새 아이디어는 무엇인가?
4. 지금은 어디에 쓰이나?
