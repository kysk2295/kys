# APEX Day 0 — 여행 준비

> 30일 동안 무엇을 배우고, AI 논문을 어떻게 읽을 것인가?

Day 0은 본편 전 워밍업입니다. 목표는 어려운 내용을 많이 배우는 것이 아니라 **논문을 읽을 때 어디를 먼저 보고, 무엇을 건너뛰어도 되는지**를 익히는 것입니다.

## 오늘의 핵심 질문

- AI 논문은 왜 처음 보면 벽처럼 느껴질까?
- 논문을 1페이지부터 끝까지 읽어야 할까?
- 모르는 수식이 나오면 멈춰야 할까?
- 30일 후 어떤 수준을 목표로 할까?

## 논문 읽기의 기본 순서

처음부터 Method의 수식을 파고들지 않습니다.

```text
1. Title
2. Abstract
3. 핵심 Figure
4. Introduction
5. Experiment Table
6. Method
7. Limitation / Conclusion
```

처음 읽을 때는 다섯 질문만 잡습니다.

```text
무슨 문제인가?
왜 기존 방식이 부족했나?
무엇을 새로 제안했나?
실험에서 실제로 좋아졌나?
무엇은 아직 해결하지 못했나?
```

## 모르는 용어를 만났을 때

모든 용어를 즉시 검색하지 않습니다.

- **A — 꼭 알아야 함:** 논문의 핵심 기여를 이해하는 데 필요
- **B — 문맥만 알면 됨:** 자세한 정의는 나중에 가능
- **C — 지금 건너뛰어도 됨:** 세부 구현, 증명, 하이퍼파라미터

논문 한 문단마다 검색을 반복하면 이야기의 흐름을 잃습니다. 먼저 전체 주장을 잡고 필요한 부분만 되돌아옵니다.

## 수식 읽기 규칙

APEX에서는 수식을 계산 문제보다 **압축된 문장**으로 봅니다.

예:

```text
y = F(x) + x
```

처음에는 이렇게 읽으면 충분합니다.

```text
결과 = 모델이 새로 계산한 변화 + 원래 입력
```

기호 하나하나를 증명하는 것은 후속 심화 과정의 역할입니다.

## 하루 학습법

```text
Session 1 — 스토리와 배경
Session 2 — 핵심 개념
Session 3 — 실제 논문 탐험
Session 4 — 현재 활용과 복습
```

읽다가 막히면 바로 질문합니다.

```text
APEX 질문: 이 문장에서 parameter가 무슨 뜻이야?
APEX 질문: 이 그림의 화살표를 처음부터 다시 설명해줘.
APEX 질문: 수식은 모르겠는데 문장으로 번역해줘.
```

## 30일 후 목표

30일 뒤 새로운 논문을 열었을 때 다음 사고가 가능해지는 것을 목표로 합니다.

```text
이 논문은 Transformer 계열이구나.
이 부분은 Attention을 변형했네.
기존 문제는 긴 문맥 처리였구나.
실험에서 Baseline과 비교했네.
이 수식의 세부 계산은 모르지만 역할은 알겠다.
새로운 개념은 이 두 개니까 이것만 추가로 공부하면 되겠다.
```
