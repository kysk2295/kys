# ATLAS Day 0 — 데이터를 잘 다룬다는 것은 무엇일까?

Day 0는 본편을 시작하기 전에 ATLAS의 관점을 세팅하는 날입니다.

## 핵심 메시지

좋은 데이터 분석가는 단순히 코드를 빨리 쓰는 사람이 아닙니다.

```text
좋은 분석
= 올바른 질문
+ 믿을 수 있는 데이터
+ 누설 없는 검증
+ 적절한 지표
+ 재현 가능한 과정
+ 운영에서의 관찰
```

ATLAS에서는 `delayed-label-monitoring`을 완성된 정답으로 보지 않습니다. 오히려 프로젝트에서 실제로 발생한 실패와 결론 수정 과정을 교재로 사용합니다.

## Day 0에서 확인할 것

- 데이터 분석과 ML 모델링의 차이
- 모델 개발과 모델 운영의 차이
- MLOps를 단순 CI/CD로 보면 부족한 이유
- 좋은 숫자보다 믿을 수 있는 숫자가 중요한 이유
- 실패 기록이 왜 훌륭한 학습 자료인지
