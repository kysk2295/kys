# ATLAS Commands

ATLAS는 LearningOS 공통 명령어를 그대로 사용합니다.

```text
ATLAS 시작
ATLAS 계속
ATLAS Day 4
ATLAS Day 4 Session 2
ATLAS 질문: PIT가 왜 leakage인지 모르겠어
ATLAS 복습
ATLAS 시험
ATLAS 심화
ATLAS 사전 PR-AUC
ATLAS 진도
ATLAS PDF
ATLAS Day 4 완료
```

## 권장 사용 흐름

```text
ATLAS 시작
→ 하루 학습
→ 중간 질문
→ ATLAS 시험
→ ATLAS Day N 완료
→ 다음 날 ATLAS 계속
```

## 질문 예시

```text
ATLAS 질문: 이 프로젝트에서 PIT와 look-ahead bias가 정확히 어떻게 연결돼?
ATLAS 질문: 왜 PR-AUC는 양성률이 바뀌면 직접 비교하면 안 돼?
ATLAS 질문: data drift와 concept drift를 프로젝트 사례로 비교해줘.
ATLAS 질문: F-013을 처음부터 쉽게 다시 설명해줘.
```

## PDF

`ATLAS PDF`는 그날 공부한 내용과 실제 질문·보충설명까지 포함한 복습용 교재를 생성하는 명령으로 사용합니다.
