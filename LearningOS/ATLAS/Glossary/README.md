# ATLAS Glossary

ATLAS에서 반복해서 등장하는 용어를 누적 정리하는 공간입니다.

초기 핵심 용어:

- Grain
- Entity / Event / Snapshot
- Primary Key / Composite Key
- Label / Target
- Point-in-Time (PIT)
- Look-ahead Bias
- Survivorship Bias
- Prevalence
- Precision / Recall
- ROC-AUC / PR-AUC
- Lift
- Calibration
- Threshold
- Walk-forward Validation
- Data Drift
- Concept Drift
- Delayed Label
- Partial Label
- Feature Contract
- Lineage
- Reproducibility
- Observability

각 용어는 실제 학습 Day에서 등장할 때 `쉬운 뜻 → 실무 의미 → delayed-label-monitoring 사례 → 흔한 오해` 순서로 확장합니다.
