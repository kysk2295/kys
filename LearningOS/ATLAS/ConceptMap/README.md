# ATLAS Concept Map

30일 동안 아래 지도를 점진적으로 채웁니다.

```text
Problem Definition
    ↓
Data Grain / Key / Label
    ↓
Data Quality
    ↓
Time Correctness / PIT
    ↓
Leakage / Survivorship Bias
    ↓
Feature / Model
    ↓
Validation
    ↓
Metrics / Calibration / Threshold
    ↓
Temporal Robustness
    ↓
Data Drift / Concept Drift
    ↓
Delayed Labels / Partial Labels
    ↓
Monitoring / Alert / Investigation
    ↓
Versioning / Lineage / Reproducibility
    ↓
MLOps System
```

## 누적 방식

각 Day가 끝날 때 오늘 개념을 이 지도 어디에 배치할지 확인합니다.

목표는 30개의 용어를 따로 외우는 것이 아니라 **하나의 ML 시스템 안에서 각 개념의 위치를 이해하는 것**입니다.
